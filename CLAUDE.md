# Perspective Studio

Pour toute demande d'illustration animée à partir d'images de référence : suivre `docs/WORKFLOW-IA.md` (briefing complet, récapitulatif validé par l'utilisateur, puis seulement construction). Ne jamais modéliser avec seulement des images. Format du modèle : `docs/FORMAT-MODELE.md`.

- Serveur local : `python3 serve.py` (127.0.0.1 uniquement). Le moteur `web/engine.wasm` n'est pas dans git : `./build.sh` (Rust requis).
- Vérifier à 390 px et à 1440 px avant de conclure, et signaler les écarts avec la référence.
- Ne pas décalquer un produit existant ni reprendre une marque ou un logo.
